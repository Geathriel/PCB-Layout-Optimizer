# PCB Layout Optimizer

PCB Layout Optimizer is a Python application for automatic placement of PCB footprints on a panel.

# Features
Automatic footprint placement
Support for custom polygon footprint shapes
Optional footprint rotation
Configurable spacing between footprints
Layout validation
Straight and contour cut path generation
Graphical user interface built with PySide6
JSON project import/export
Project generation from footprint images
# Technologies
Python 3
PySide6
Shapely
Pillow
Matplotlib
Pytest
# Usage
Load a project JSON file or generate one from images.
Configure layout settings.
Generate the layout.
Review the generated placement, validation results, and cut paths.
